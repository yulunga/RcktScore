# Manual Testing

**Naming:** HitnScore is the customer-facing application. `RcktScore` is the internal project and repository code name.

Manual testing stays important even when automation grows.

Use this area for:

- UI and UX checks
- mobile and tablet layout passes
- accessibility spot checks
- release walkthroughs
- exploratory testing after major changes

Automation tells you whether the app still works.

Manual testing tells you whether the app still feels good to use.
